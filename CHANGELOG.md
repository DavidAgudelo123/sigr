# Changelog

## [1.0.0-baseline] - 2026-11-11
### Añadido
- Módulo de autenticación de usuarios con roles (cliente, mesero, administrador).
- Módulo de menú digital con CRUD de platos y categorías.
- Módulo de registro y seguimiento de pedidos por estado.
- Módulo de reservas por fecha y hora con asignación de mesa.
- Módulo de cierre de caja y reporte de ventas diarias.
- Servidor HTTP con rutas REST y endpoint /health.
- Pruebas básicas de integración (node:test).
- Documentación: README.md, CHANGELOG.md, LICENSE.txt, docs/.
